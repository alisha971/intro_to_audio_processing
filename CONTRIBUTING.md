# Contributing

Thanks for your interest! This is a learning journal, and contributions of any size are welcome: typo fixes, clearer explanations, new notebooks, or paper suggestions.

## How to contribute

1. Open an issue to discuss larger changes (optional for small fixes).
2. Fork the repo and create a branch, e.g. `git checkout -b add-pitch-tracking-notebook`.
3. Make your changes following the guidelines below.
4. Open a pull request describing what you changed and why.

## Guidelines

- **Notes** (`notes/`): beginner-friendly Markdown, one topic per file, named `NN-topic-name.md`. Define jargon on first use.
- **Notebooks** (`notebooks/`): must run top to bottom, include short explanations between cells, and name files to match the related note.
- **Audio data** (`data/`): keep files small and legally usable (state the source and licence). Link to large datasets instead of committing them.
- **Papers**: when suggesting a paper, include the title, authors, year, a link, and one or two sentences on why it helps a beginner.
- **Credit sources** and don't copy text from books or papers.
- Be kind and constructive. Everyone here is learning.
